# Публикация IsoMap

Аккаунты и загрузку вы делаете сами. Здесь всё, что нужно вставить. Обе площадки проверяют новые проекты модерацией, поэтому мод появится не сразу. Формы на сайтах могут отличаться от этого описания.

## Файлы

| Файл | Для чего |
| --- | --- |
| `isomap-neoforge-1.21.1-1.0.0.jar` | Сам мод |
| `logo.png` | Иконка проекта, 512×512 |
| `description_en.md` | Основное описание на английском |
| `description_ru.md` | Русская версия (на площадках обычно одно описание, можно добавить ниже английского) |
| `gallery/` | Скриншоты для галереи |

## Общие поля

- **Название:** IsoMap
- **Краткое описание:** A minimalist client-side 2.5D minimap with a free camera, cave view, waypoints with tags and death markers.
- **Версия:** 1.0.0
- **Minecraft:** 1.21.1
- **Загрузчик:** NeoForge
- **Лицензия:** MIT
- **Тип релиза:** Release начиная с 1.3.0 (до неё Beta). Перед выпуском проверены выделенный сервер NeoForge, игрок без мода, Sodium и Iris с шейдером
- **Зависимости:** только NeoForge

## Modrinth

1. Зарегистрируйтесь на https://modrinth.com и нажмите **Create a project**.
2. Тип проекта: **Mod**. Название IsoMap, адрес `isomap-minimap` (короткий `isomap` оказался занят скрытым проектом).
3. Загрузите `logo.png`, вставьте краткое описание и текст из `description_en.md`.
4. Категория: **Utility**.
5. Окружение: **Client: Required**, **Server: Optional** (начиная с 1.2.0, из-за пингов).
6. Лицензия: **MIT**.
7. Загрузите скриншоты в раздел **Gallery**. Главным изображением сделайте `1_minimap.png`.
8. В разделе **Versions** создайте версию 1.0.0, приложите jar, укажите NeoForge, 1.21.1, канал Beta.
9. Отправьте проект на модерацию.

## CurseForge

1. Зарегистрируйтесь на https://www.curseforge.com, откройте консоль авторов https://authors.curseforge.com и создайте проект.
2. Раздел **Minecraft → Mods**. Название IsoMap. Свободно ли имя, автоматически проверить не удалось: сайт блокирует такие запросы.
3. Категория: **Map and Information**.
4. Загрузите `logo.png`, вставьте краткое описание и текст из `description_en.md`.
5. Лицензия: **MIT License**.
6. В разделе **Files** загрузите jar: Release Type **Beta**, Game Version **1.21.1**, Mod Loader **NeoForge**, окружение **Client**.
7. Добавьте скриншоты в раздел **Images** и отправьте проект на проверку.
